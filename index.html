Privacy Policy for AdSense Ad Review Inspector

Effective date: August 12, 2026

AdSense Ad Review Inspector helps Google AdSense publishers review advertising creatives and analyze performance metrics displayed in Google AdSense Ad Review Center.

Data processed

The extension processes website content visible on supported AdSense Ad Review Center pages, including creative identifiers, advertiser domains and destination URLs, revenue, impressions, CTR, geography, ad status, and visible chart tooltip values. Users may also create notes and tags.

Use, storage, and transmission

Data is used only for local creative analysis, RPM and CTR ranking, reports, notes, exports, and daily chart visualization. Processing occurs locally. Reports, settings, notes, snapshots, and diagnostic logs remain in Chrome extension storage on the user's device. No data is transmitted to the developer, analytics providers, advertising services, external servers, or third parties. Exports are downloaded only after an explicit user action.

Data not collected

The extension does not collect or read AdSense cookies, passwords, authentication tokens, payment credentials, network request or response bodies, AdSense localStorage, AdSense sessionStorage, AdSense IndexedDB databases, or unrelated browsing history. It does not use analytics, telemetry, advertising SDKs, or remote code.

Debugger permission

Chrome's debugger permission is used only after a user selects Load daily history and confirms an in-product disclosure. The extension temporarily moves a virtual pointer over visible charts in the current AdSense detail tab and reads tooltip text. It never enables network interception and detaches when the operation finishes, fails, or is canceled.

Deletion

Users can delete all stored data from the extension Options page by selecting Clear extension data, or by removing the extension.

Sharing and Limited Use

The developer does not sell, rent, share, or transfer user data. Data is not used for advertising, credit decisions, or unrelated purposes. Use of information received from Google services complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.
